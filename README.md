# Hospital Management System

A modern Hospital Management System built with Next.js, Prisma, MySQL, and Tailwind CSS. The application helps hospitals and clinics manage patients, doctors, appointments, billing, prescriptions, and administrative operations through a centralized dashboard.

## Features

- Secure Admin Authentication
- Patient Registration & Management
- Doctor Management
- Appointment Scheduling
- Token Management System
- Billing & Invoice Generation
- Prescription Management
- Search & Filter Records
- Responsive Dashboard UI
- MySQL Database Integration
- Prisma ORM for Database Management

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma ORM
- MySQL
- JWT Authentication

## Project Goals

The objective of this project is to digitize hospital workflows, reduce paperwork, improve appointment handling, and provide efficient management of patient records and billing processes.
